# 100x Rush

A 60-second trading game: start with $1,000, go long or short at up to 100x on charts stitched from real market history, and challenge friends to beat your score on the exact same chart.

Play: https://belladong-prog.github.io/100x-rush/

It is a single static page. It needs no account, has no server or tracking, and stores nothing except your own best scores in your browser. No real money is involved.
